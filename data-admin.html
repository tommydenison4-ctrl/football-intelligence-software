Supabase Database Status

This page is intentionally read-only for staff. It checks whether the V2 tables are available and whether the selected opponent has centralized data.

V2 data model

Run supabase_v2_schema.sql once in the Supabase SQL Editor. Existing projects and plays stay in place; the new tables add opponents, player profiles, depth charts, reports and shared platform settings.

Data rule

Frontend pages contain presentation + football logic only. Supabase contains opponent data, plays, players, depth charts, reports and settings. One opponent selection is shared across the platform.
